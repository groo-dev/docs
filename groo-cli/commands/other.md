# Other Commands

## restart

Restart running services.

```bash
groo restart
```

## stop

Stop all services in the current project.

```bash
groo stop
```

## list

List all projects with running services.

```bash
groo list
```

## open

Open a service URL in your browser.

```bash
groo open <service>
```
